Gestes

  • Toucher un dé en haut : l'ajouter au tapis
  • Toucher un dé sur le tapis : le lancer
  • Appui long sur un dé : le retirer
  • Glisser-déposer : déplacer · lâcher avec élan : lancer manuel
  • D% : dizaines (00–90) · avec un D10 : 00 + 0 = 100
  • 🎲 Lancer : lance tous les dés (+ total, clic dessus = masquer)
  • 🗑 Vider : tout retirer, sans confirmation
